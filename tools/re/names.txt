# Noms des fonctions et des données du jeu, que ghidra_names.py donne au projet Ghidra.
#
# Chaque nom vient d'un fait de docs/FORMATS.md, prouvé dans le code ou sur la ROM ; la description
# le résume et devient le commentaire de la fonction ou de la donnée dans Ghidra.
#
# Une ligne : l'adresse (« ovN: » devant pour l'overlay N, comme pour decomp.py), le nom
# (identifiant anglais, unique), puis la description. Une adresse que le document cite au milieu
# d'une fonction (un appel, une lecture) nomme la fonction qui la contient, donnée ici par son début.
# Les fonctions sont en Thumb, sauf celles de la section [fonctions en ARM] (le code ARM de
# l'ARM9) ; ghidra_names.py le vérifie. Les commandes de script et d'effets sont désignées par leur
# numéro en hexadécimal : la fonction que leur table indique devient script_cmd_085_trainer_battle ;
# les commandes sans ligne gardent un nom générique (script_cmd_0A5, effect_cmd_2E).
